## ⛓️ The Neural Pipeline (Technical Walkthrough)

How Pixora transforms a "vibe" into a production-ready interface:

1.  **Ingestion & Enhancement**: The user enters a raw intent. The **Gemini 3.1 Flash Lite Optimizer** enriches the prompt with technical design tokens and accessibility requirements.
2.  **Parallel Dispatch**: The optimized specification is dispatched to five AI agents simultaneously via a specialized multi-thread handler.
3.  **Tool-Calling Generation**: Each agent utilizes tool-calling to generate a valid, self-contained HTML/CSS/JS payload.
4.  **Sandbox Isolation**: The generated code is injected into individual **CodeMirror** instances, ensuring that styles from one design do not leak into another.
5.  **Reactive Preview**: A virtual DOM bridge renders the sandbox content into a live preview pane, allowing for instant visual verification.

## 🚀 Performance & Architectural Integrity

To maintain a "zero-lag" experience while running five SOTA models, Pixora utilizes a cutting-edge architectural stack:

*   **Asynchronous Parallelism**: All 5 agents are invoked in parallel. We use React 19's concurrent rendering capabilities to ensure the UI remains responsive even during heavy data streaming.
*   **Lazy Sandbox Initialization**: Agent columns and their respective CodeMirror instances are initialized lazily to minimize initial memory footprint.
*   **GPU-Accelerated Visuals**: Background shaders and particle systems are offloaded to the GPU via Three.js, ensuring that the "Neural Vibe" doesn't consume CPU cycles needed for AI processing.
